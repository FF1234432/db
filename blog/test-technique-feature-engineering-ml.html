1Encodage des variables categorielles

Question discriminante

Quand utilisez-vous One-Hot Encoding vs Target Encoding vs Ordinal Encoding ?

import pandas as pd from sklearn.preprocessing import LabelEncoder from category_encoders import TargetEncoder # One-Hot Encoding : variables nominales a faible cardinalite (<15 valeurs) pd.get_dummies(df, columns=['genre', 'region'], drop_first=True) # Target Encoding : variables a forte cardinalite (>15 valeurs) # Encode par la moyenne de la target par categorie enc = TargetEncoder(cols=['city', 'product_category']) df_encoded = enc.fit_transform(df, df['churned']) # Attention : risque de data leakage sur le train set # Toujours utiliser cross-validation ou leave-one-out # Ordinal Encoding : variables ordonnees order_map = {'faible': 0, 'moyen': 1, 'eleve': 2} df['niveau_encoded'] = df['niveau'].map(order_map)
  • One-Hot — faible cardinalite, pas d ordre. Cree N colonnes binaires
  • Target Encoding — forte cardinalite. Encode la relation avec la variable cible
  • Ordinal — variables avec un ordre naturel (faible/moyen/fort)
  • Frequency Encoding — encode par la frequence d apparition. Bon compromis

2Gestion des valeurs manquantes

Question discriminante

Quelles strategies de gestion des valeurs manquantes utilisez-vous ?

from sklearn.impute import SimpleImputer, KNNImputer # Imputation simple imputer_median = SimpleImputer(strategy='median') # numerique robuste imputer_mode = SimpleImputer(strategy='most_frequent') # categoriel # KNN Imputer : impute selon les k voisins les plus proches knn_imputer = KNNImputer(n_neighbors=5) # Ajouter un indicateur de valeur manquante df['income_missing'] = df['income'].isna().astype(int) df['income'].fillna(df['income'].median(), inplace=True) # Supprimer : seulement si <5% de valeurs manquantes et MCAR # (Missing Completely At Random)
  • MCAR, MAR, MNAR — comprendre pourquoi la valeur est manquante avant de choisir la strategie
  • Indicateur de missing — toujours ajouter une colonne binaire indiquant qu une valeur etait manquante
  • Ne jamais imputer sur le test set — calculer les statistiques d imputation uniquement sur le train set

3Features temporelles

Question discriminante

Quelles features temporelles creez-vous classiquement pour une serie temporelle ?

df['date'] = pd.to_datetime(df['date']) # Features calendaires df['year'] = df['date'].dt.year df['month'] = df['date'].dt.month df['day_of_week'] = df['date'].dt.dayofweek df['is_weekend'] = df['day_of_week'].isin([5, 6]).astype(int) df['quarter'] = df['date'].dt.quarter df['is_month_end']= df['date'].dt.is_month_end.astype(int) # Encodage cyclique (eviter la discontinuite 12->1 pour les mois) import numpy as np df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12) df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12) # Lag features (comportement passe) df['revenue_lag_7d'] = df.groupby('customer_id')['revenue'].shift(7) df['revenue_lag_30d'] = df.groupby('customer_id')['revenue'].shift(30) df['revenue_roll_mean_7d'] = df.groupby('customer_id')['revenue'].transform( lambda x: x.rolling(7).mean())

4Normalisation : quand et comment

Question discriminante

Pourquoi les arbres de decision n ont-ils pas besoin de normalisation ? Et les reseaux de neurones ?

  • StandardScaler — centre et reduit (mean=0, std=1). Pour les algos sensibles a l echelle : regression logistique, SVM, KNN, reseaux de neurones
  • MinMaxScaler — echelle [0, 1]. Pour les reseaux de neurones, quand on connait les bornes
  • RobustScaler — base sur la mediane et l IQR. Robuste aux outliers
  • Pas necessaire — arbres de decision, Random Forest, XGBoost, LightGBM. Ils partitionnent sur des seuils, pas sur des distances
  • Regle — toujours fitter le scaler sur le train set et l appliquer (transform) sur le test set

6Data leakage : le piege majeur

Question discriminante

Qu est-ce que le data leakage ? Donnez un exemple concret.

  • Data leakage — les features d entrainement contiennent de l information sur la target qui ne sera pas disponible en production. Le modele performe tres bien sur le test set mais echoue en production
  • Exemple classique — predire le churn avec une feature 'dernier_appel_service_client' creee APRES la decision de churn. En prod, cette info n existe pas encore au moment de la prediction
  • Target encoding mal fait — calculer le target encoding sur tout le dataset avant le train/test split
  • Prevention — construire les features en respectant la temporalite, ne jamais fitter les encodeurs sur le test set
