4Déploiement canary et shadow mode

Question discriminante

Quelle est la différence entre shadow mode et canary deployment pour un modèle ML ?

  • Shadow mode — le nouveau modèle reçoit les mêmes requêtes que le modèle de prod mais ses réponses ne sont pas retournées aux utilisateurs. Permet de comparer sans risque
  • Canary deployment — 5-10% du trafic est envoyé au nouveau modèle. Les utilisateurs reçoivent réellement ses prédictions. Permet de mesurer l impact réel
  • A/B testing de modèles — variante du canary avec assignation déterministe (même user → même modèle) pour des résultats cohérents
  • Rollback — si les métriques se dégradent, basculer immédiatement 100% du trafic vers l ancien modèle
