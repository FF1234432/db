Tableau est intuitif en surface. Mais entre creer un graphique et concevoir un dashboard analytique, l'ecart est considerable.

Tableau est intuitif en surface. Mais entre creer un graphique et concevoir un dashboard avec des LOD expressions, l'ecart est considerable.

1Vues et visualisations

Question discriminante

Comment choisissez-vous le type de visualisation adapte a une question metier ?

  • Dual axis — combiner deux mesures sur des axes differents
  • Actions : filter, highlight, URL entre feuilles
  • Parametres — laisser l'utilisateur choisir une mesure

2Calculs et formules

Question discriminante

Difference entre un calculated field et une table calculation ?

Les calculated fields operent au niveau de la source (avant agregation). Les table calculations operent sur ce qui est affiche (apres agregation).

  • RUNNING_SUM, WINDOW_AVG, RANK, INDEX
  • Sets et groupes — segmenter dynamiquement les valeurs

3LOD expressions : le vrai differenciateur

Question discriminante

Difference entre FIXED, INCLUDE et EXCLUDE ? Un cas d'usage pour chacune.

FIXED : calcul a une granularite precise independamment de la vue (premier achat par client). INCLUDE : ajoute une dimension. EXCLUDE : retire une dimension.

Signal d'alerte : un profil qui n'a jamais utilise de LOD expression ne peut pas construire de dashboards analytiques avances.

4Tableau Prep et gouvernance

Question discriminante

Quand utilisez-vous Tableau Prep plutot que de preparer les donnees en SQL ?

  • Published data sources — extraits certifies partages
  • Certifier les sources — gouvernance dans Tableau Server/Cloud

5Performance

Question discriminante Senior

Votre dashboard Tableau met 45 secondes a charger. Par quoi commencez-vous ?

  • Performance Recorder — identifier les requetes lentes
  • Context filters — filtres appliques en premier
  • Extraits vs connexion live — quand utiliser l'un ou l'autre
